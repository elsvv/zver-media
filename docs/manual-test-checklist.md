# Ручная проверка на железе

## Этап 1
- [ ] Импорт: закинуть FLAC-альбом через Files app в папку Zver («On My iPhone») → появился в библиотеке после pull-to-refresh
- [ ] Воспроизведение FLAC 16/44.1 и hi-res 24/96+
- [ ] ЦАП: индикатор частоты на ЦАПе показывает частоту ТРЕКА (44.1 → 96 при смене трека)
- [ ] Локскрин: артворк, прогресс, play/pause/next работают
- [ ] Фон: свернуть приложение — музыка играет дальше
- [ ] Конец трека → авто-переход на следующий
- [ ] Seek в полноэкранном плеере и с локскрина
- [ ] Выдернуть ЦАП во время игры → пауза, не краш
- [ ] Входящий звонок → пауза, после звонка продолжилось
- [ ] Убить приложение, открыть → библиотека на месте
- [ ] Мини-плеер: появляется при воспроизведении, прогресс идёт, тап открывает полный экран

## Этап 2

- [ ] Gapless: на стыке двух треков одного альбома (одинаковая частота) — без щелчка и паузы, следующий трек начинается мгновенно
- [ ] Обложка из folder.jpg: альбом In Rainbows (треки без встроенной обложки, folder.jpg в папке) показывает обложку в списках и плеере
- [ ] Папка без тегов ALBUM: треки получают альбом по имени папки (не «Без альбома»)
- [ ] Плейлист: создать, добавить треки, убить приложение, открыть → плейлист и порядок треков на месте
- [ ] Поиск: подстрока названия трека (в любом регистре) находит трек, тап играет
- [ ] Рестарт: убить приложение, открыть → библиотека видна мгновенно, без ожидания скана

## Этап 3 — синк Mac ↔ iPhone

Подготовка: Мак и iPhone в одной Wi-Fi-сети, на Маке запущен `ZverMac` (иконка в меню-баре).

### На Маке (ZverMac)
- [ ] Drag-drop: перетащить папку альбома (напр. `Radiohead - In Rainbows (2007) [24-44.1 WEB FLAC]`) в окно → распарсились теги, показалось превью с обложкой и списком треков
- [ ] Редактор метадаты: изменить название альбома / артиста / обложку → правка видна в превью, **исходные аудиофайлы на диске не изменились** (проверить дату модификации/теги файла в папке — не тронуты)
- [ ] «В очередь»: альбом попал в исходящую очередь, виден статус раздачи

### На телефоне (ZverIOS, экран «Импорт с Мака»)
- [ ] Обнаружение: Мак появляется в списке найденных (по имени Мака)
- [ ] Pairing (первый раз): Мак показывает 6-значный код, ввод кода на телефоне → успех, токен сохранён; повторный заход на тот же Мак pairing не запрашивает
- [ ] Загрузка очереди: старт импорта → идёт прогресс по файлам/альбому
- [ ] Обрыв сети на середине: выключить Wi-Fi/унести телефон и вернуть → докачка продолжается с места (не качает заново уже скачанное)
- [ ] Целостность: SHA-сверка отбраковывает битый файл — повреждённый трек перекачивается, в библиотеку попадает корректный

### Результат на телефоне
- [ ] Правки с Мака видны в каталоге телефона: изменённые на Маке название/обложка/артист отображаются в библиотеке (sidecar `album.zvermeta.json` лёг рядом с треками, overlay применился)
- [ ] Перезаливка того же альбома: повторно залить альбом с Мака → обновился на месте, **без дублей** в библиотеке
- [ ] Подтверждение Маку: после успешного импорта альбом **ушёл из очереди** на Маке (получен confirm)
