# Ручная проверка на железе

## Этап 1
- [ ] Импорт: закинуть FLAC-альбом через Files app в папку Zver («On My iPhone») → появился в библиотеке после pull-to-refresh
- [ ] Воспроизведение FLAC 16/44.1 и hi-res 24/96+
- [ ] ЦАП: индикатор частоты на ЦАПе показывает частоту ТРЕКА (44.1 → 96 при смене трека)
- [ ] Локскрин: артворк, прогресс, play/pause/next работают
- [ ] Фон: свернуть приложение — музыка играет дальше
- [ ] Конец трека → авто-переход на следующий
- [ ] Seek в полноэкранном плеере и с локскрина
- [ ] Выдернуть ЦАП во время игры → пауза, не краш
- [ ] Входящий звонок → пауза, после звонка продолжилось
- [ ] Убить приложение, открыть → библиотека на месте
- [ ] Мини-плеер: появляется при воспроизведении, прогресс идёт, тап открывает полный экран

## Этап 2

- [ ] Gapless: на стыке двух треков одного альбома (одинаковая частота) — без щелчка и паузы, следующий трек начинается мгновенно
- [ ] Обложка из folder.jpg: альбом In Rainbows (треки без встроенной обложки, folder.jpg в папке) показывает обложку в списках и плеере
- [ ] Папка без тегов ALBUM: треки получают альбом по имени папки (не «Без альбома»)
- [ ] Плейлист: создать, добавить треки, убить приложение, открыть → плейлист и порядок треков на месте
- [ ] Поиск: подстрока названия трека (в любом регистре) находит трек, тап играет
- [ ] Рестарт: убить приложение, открыть → библиотека видна мгновенно, без ожидания скана
