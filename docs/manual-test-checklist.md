# Ручная проверка на железе

## Этап 1
- [ ] Импорт: закинуть FLAC-альбом через Files app в папку Zver («On My iPhone») → появился в библиотеке после pull-to-refresh
- [ ] Воспроизведение FLAC 16/44.1 и hi-res 24/96+
- [ ] ЦАП: индикатор частоты на ЦАПе показывает частоту ТРЕКА (44.1 → 96 при смене трека)
- [ ] Локскрин: артворк, прогресс, play/pause/next работают
- [ ] Фон: свернуть приложение — музыка играет дальше
- [ ] Конец трека → авто-переход на следующий
- [ ] Seek в полноэкранном плеере и с локскрина
- [ ] Выдернуть ЦАП во время игры → пауза, не краш
- [ ] Входящий звонок → пауза, после звонка продолжилось
- [ ] Убить приложение, открыть → библиотека на месте
- [ ] Мини-плеер: появляется при воспроизведении, прогресс идёт, тап открывает полный экран

## Этап 2

- [ ] Gapless: на стыке двух треков одного альбома (одинаковая частота) — без щелчка и паузы, следующий трек начинается мгновенно
- [ ] Обложка из folder.jpg: альбом In Rainbows (треки без встроенной обложки, folder.jpg в папке) показывает обложку в списках и плеере
- [ ] Папка без тегов ALBUM: треки получают альбом по имени папки (не «Без альбома»)
- [ ] Плейлист: создать, добавить треки, убить приложение, открыть → плейлист и порядок треков на месте
- [ ] Поиск: подстрока названия трека (в любом регистре) находит трек, тап играет
- [ ] Рестарт: убить приложение, открыть → библиотека видна мгновенно, без ожидания скана

## Этап 3 — синк Mac ↔ iPhone

Подготовка: Мак и iPhone в одной Wi-Fi-сети, на Маке запущен `ZverMac` (иконка в меню-баре).

### На Маке (ZverMac)
- [ ] Drag-drop: перетащить папку альбома (напр. `Radiohead - In Rainbows (2007) [24-44.1 WEB FLAC]`) в окно → распарсились теги, показалось превью с обложкой и списком треков
- [ ] Редактор метадаты: изменить название альбома / артиста / обложку → правка видна в превью, **исходные аудиофайлы на диске не изменились** (проверить дату модификации/теги файла в папке — не тронуты)
- [ ] «В очередь»: альбом попал в исходящую очередь, виден статус раздачи

### На телефоне (ZverIOS, экран «Импорт с Мака»)
- [ ] Обнаружение: Мак появляется в списке найденных (по имени Мака)
- [ ] Pairing (первый раз): Мак показывает 6-значный код, ввод кода на телефоне → успех, токен сохранён; повторный заход на тот же Мак pairing не запрашивает
- [ ] Загрузка очереди: старт импорта → идёт прогресс по файлам/альбому
- [ ] Обрыв сети на середине: выключить Wi-Fi/унести телефон и вернуть → докачка продолжается с места (не качает заново уже скачанное)
- [ ] Целостность: SHA-сверка отбраковывает битый файл — повреждённый трек перекачивается, в библиотеку попадает корректный

### Результат на телефоне
- [ ] Правки с Мака видны в каталоге телефона: изменённые на Маке название/обложка/артист отображаются в библиотеке (sidecar `album.zvermeta.json` лёг рядом с треками, overlay применился)
- [ ] Перезаливка того же альбома: повторно залить альбом с Мака → обновился на месте, **без дублей** в библиотеке
- [ ] Подтверждение Маку: после успешного импорта альбом **ушёл из очереди** на Маке (получен confirm)

## Этап 4 — Яндекс.Диск

Проверка облака — на устройстве у владельца (сети/реального Яндекс.Диска в CI нет;
пакеты и компиляция таргетов зелёные автоматически). Подготовка: владелец получил
~годовой OAuth-токен Яндекс.Диска (scope `cloud_api:disk.app_folder`).

### Авторизация
- [ ] Настройки → вставить токен → «Войти»: статус сменился на «Авторизован», токен лёг в Keychain (после рестарта приложения вход сохранён, повторно вставлять не нужно)
- [ ] «Выйти»: статус сбросился, токен удалён из Keychain
- [ ] Битый/пустой токен: «Войти» не авторизует (нет ложного «Авторизован»)

### Автобэкап
- [ ] Новый альбом (импортирован с Мака или закинут в Documents) автоматически выгружается в облако → на треках появляется бейдж ☁︎✓ (`backedUp`)
- [ ] Бэкап каталога: после батча в облаке лежит `catalog.sqlite.backup` (виден в Яндекс.Диске → Приложения → Zver)
- [ ] Облачная раскладка верна: файлы в `library/<albumId>/<fileName>`, имена зеркалят локальные

### Выгрузка (offload) и удаление только по checksum
- [ ] Swipe по `backedUp`-треку → «Выгрузить»: локальный файл удалён, бейдж стал ☁︎ (`remote`)
- [ ] Удаление локального файла НЕ происходит без подтверждённого checksum: если облачный SHA-256 не совпал с локальным — файл остаётся на устройстве, трек НЕ переходит в `remote`
- [ ] После выгрузки место на устройстве освободилось (файл физически удалён из `Documents/Library/...`)

### Скачивание и воспроизведение
- [ ] Swipe по `remote`-треку → «Скачать»: файл вернулся на устройство, бейдж стал ☁︎✓ (`backedUp`), трек играет
- [ ] Тап по `remote`-треку (файла на устройстве нет) НЕ роняет приложение и НЕ пытается играть пустоту — ведёт на «Скачать»
- [ ] Скачанный трек проходит SHA-сверку и раскладывается атомарно (битый перекачивается, в библиотеку попадает корректный)

### Устойчивость передачи
- [ ] Обрыв сети на середине аплоада: выключить Wi-Fi и вернуть → выгрузка продолжается/повторяется, в итоге трек `backedUp` (аплоад — best-effort: при обрыве перезапрос href и повтор PUT)
- [ ] Обрыв сети на середине скачивания → докачка продолжается с места (не качает заново уже скачанное)
- [ ] 429 (Too Many Requests) от Яндекса НЕ валит очередь: передача уходит в backoff (уважает `Retry-After`) и затем завершается; остальные элементы очереди не теряются
- [ ] Свернуть приложение во время передачи → фоновая сессия продолжает (или корректно докачивает после возврата)

### Восстановление после переустановки
- [ ] Удалить и переустановить приложение (или новое устройство) → войти токеном → Настройки → «Восстановить из облака»: скачивается `catalog.sqlite.backup`, вся библиотека показывается как ☁︎ `remote`
- [ ] Качнуть нужный трек из восстановленной библиотеки → он скачивается и играет

### Mac-guard (миграция каталога v2 не сломала Мак)
- [ ] `ZverMac` по-прежнему запускается (иконка в меню-баре), парсит дропнутую папку и раздаёт очередь по HTTP — миграция каталога v2 (этап 4, iOS-only) не задела Mac-компаньон

## Этап 5 — Пульт с Мака

Проверка пульта — на железе у владельца (симрантаймов/сети в CI нет; пакеты и
компиляция обоих таргетов зелёные автоматически). Подготовка: iPhone и Mac в
одной Wi-Fi-сети, на iPhone играет/готов играть альбом, `ZverMac` запущен.

### Включение пульта и обнаружение
- [ ] На iPhone: Настройки → секция «Пульт» → включить тумблер «Пульт с Мака» (WS-сервер поднялся, iPhone анонсит `_zver._tcp` с `svc=remote`)
- [ ] На Маке: открыть окно «Пульт» (меню-бар → «Открыть пульт») → iPhone появляется в обнаружении (по имени), синк-сервис самого Мака пультом НЕ показывается (фильтр `svc=remote`)

### Сопряжение (первый раз)
- [ ] iPhone показывает 6-значный код сопряжения; ввод этого кода на Маке → успех, токен сохранён в Keychain Мака (сервис-ключ `zver-remote`)
- [ ] Повторное подключение того же Мака pairing НЕ запрашивает — Mac шлёт `hello{token}` первым сообщением, iPhone отвечает `helloAck` и пульт сразу активен
- [ ] Неверный код на Маке → сопряжение отклонено, команды не принимаются (iPhone не выпустил токен)

### Транспорт с Мака
- [ ] Кнопки play/pause/togglePlayPause/next/previous в окне «Пульт» мгновенно меняют воспроизведение на iPhone (задержка в миллисекунды)
- [ ] Слайдер позиции на Маке → `seek`: позиция на iPhone прыгает точно туда
- [ ] Команды с Мака и системные команды (локскрин/Control Center) сосуществуют — одна не блокирует другую

### Отражение состояния на Маке
- [ ] Смена трека на iPhone (конец трека / next с самого телефона) отражается в окне «Пульт» (трек, артист, альбом, очередь, индекс обновились)
- [ ] Позиция в окне «Пульт» идёт плавно (интерполируется между пушами при `playing`), при паузе — стоит
- [ ] Изменение каталога на iPhone (импорт нового альбома) обновляет список альбомов в пульте (`library` пушнулся)

### Браузинг библиотеки и запуск альбома
- [ ] Список альбомов iPhone виден в окне «Пульт» (id/title/artist/year/число треков), без локальных URL/файлов
- [ ] Тап по альбому подтягивает его треки (`requestAlbumTracks` → `albumTracks`)
- [ ] Запуск альбома с Мака (`playAlbum`, в т.ч. с конкретного трека) → iPhone резолвит альбом из каталога и начинает играть с нужного индекса

### Режим «всегда на связи»
- [ ] iPhone: Настройки → «Пульт» → режим паузы = «Всегда на связи»; поставить на паузу с iPhone или с Мака
- [ ] На паузе пульт остаётся активным: команды (play/next/seek/playAlbum) доходят и выполняются мгновенно, без необходимости будить телефон (keep-alive-тишина держит приложение живым, ЦАП захвачен)

### Режим «экономный»
- [ ] iPhone: режим паузы = «Экономный» (дефолт); поставить на паузу и подождать суспенда приложения
- [ ] Пульт «слепнет» на паузе (Mac показывает потерю связи), команды не доходят, пока телефон спит
- [ ] Оживить iPhone с локскрина/Control Center (нажать play или открыть приложение) → пульт снова на связи, состояние подтянулось

### Деградация и переподключение
- [ ] iPhone ушёл из сети (выключить Wi-Fi на телефоне / унести) → окно «Пульт» на Маке показывает «iPhone не в сети»
- [ ] iPhone вернулся в сеть → пульт автоматически переподключается, состояние и библиотека подтягиваются (повторный pairing не нужен)

### Регресс этапа 1 (не сломали локскрин/ЦАП)
- [ ] MPRemoteCommandCenter/локскрин/Control Center по-прежнему работают: артворк, прогресс, play/pause/next/seek с локскрина — как раньше
- [ ] Gapless на стыке треков альбома по-прежнему без щелчка/паузы, частота ЦАПа меняется под трек — keep-alive-нода и пульт ничего не сломали

## Этап 6 — Внешний импорт (Bandcamp / Internet Archive / файлы)

Проверка на устройстве у владельца (реального интернета/Bandcamp-аккаунта/IA в CI
нет; пакеты `ZverImport`/`ZverMetadata` и сборка app-таргета зелёные автоматически).

### «Открыть в Zver Media» (системный импорт)
- [ ] Safari: скачать zip-альбом с Bandcamp в Safari → «Поделиться» → «Открыть в Zver Media» → баннер «Импортирован <артист — альбом>», альбом в библиотеке после рескана
- [ ] Safari: одиночный `.flac` (прямая ссылка) → «Открыть в Zver Media» → трек в библиотеке
- [ ] Files (On My iPhone / iCloud Drive): долгий тап по zip → «Поделиться» → Zver → импорт; **исходник в Files НЕ удалён** (удаляется только staging-копия)
- [ ] Files: одиночный `.flac` из Files → импорт
- [ ] AirDrop: принять zip и одиночный flac с Мака/другого устройства → выбрать «Zver» → импорт, баннер
- [ ] Битый/некорректный zip через «Открыть в Zver» → баннер «Импорт не удался», приложение не падает, мусор в tmp не остаётся
- [ ] Inbox не течёт в скан: файл, принятый через «Скопировать в Zver»/AirDrop, до импорта НЕ виден треком в библиотеке (скан пропускает `Documents/Inbox`)

### Bandcamp
- [ ] Логин переживает перезапуск: войти в аккаунт в webview → убить приложение → снова открыть Bandcamp: логин сохранён (куки персистентны), коллекция купленного доступна для redownload
- [ ] $0-релиз: найти name-your-price ($0) релиз → buy → $0 → download → выбрать FLAC → плашка прогресса → «Импорт…» → «Готово», альбом в библиотеке
- [ ] 24-bit: скачать hi-res релиз (24-bit) → в плеере/на индикаторе ЦАПа битность и частота сохранены (24/96 остаётся 24/96, без даунсемпла)
- [ ] Предупреждение MVP: во время активной загрузки видна плашка «Не закрывайте приложение — загрузка прервётся»
- [ ] Плашка прогресса видна и после «назад» в селектор источников (переживает уход с экрана webview)
- [ ] Тулбар навигации: назад/вперёд/домой работают, кнопки дизейблятся по состоянию

### Internet Archive (Live Music Archive)
- [ ] Поиск: ввести артиста/название → карточки концертов (title, creator, year, downloads), сортировка по популярности
- [ ] Экран релиза: список FLAC-файлов (включая `24bit Flac`), MP3/обложки/логи отфильтрованы
- [ ] «Скачать альбом»: последовательная очередь качает файлы → импорт → рескан → альбом в библиотеке
- [ ] Обрыв сети на середине: выключить Wi-Fi во время загрузки IA-концерта и вернуть → докачка продолжается с места (Range 206), уже скачанный префикс не перекачивается

### Селектор источников и идемпотентность
- [ ] Вкладка «Импорт» — селектор: «С Мака», «Bandcamp», «Internet Archive», «Из файлов»; «С Мака» работает без регресса (этап 3)
- [ ] «Из файлов» (`fileImporter`): выбрать смешанный набор (zip + одиночные flac) → zip'ы разложены как альбомы, россыпь сгруппирована по тегам
- [ ] Повторный импорт того же альбома (любым путём: Bandcamp/IA/Файлы/«Открыть в Zver») НЕ плодит дублей — недостающие файлы докладываются, существующие не трогаются
