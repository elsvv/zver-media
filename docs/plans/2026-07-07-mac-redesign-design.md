# ZverMac: полноценное приложение (окно, сайдбар, пульт с обложками, синк с компа)

Этап 3 из 3. Сейчас ZverMac — LSUIElement в меню-баре с двумя независимыми
окнами («Синк» и «Пульт»): нет в Dock/alt-tab, пульт — плоский список без
обложек, прогресс синка виден только на телефоне, конфирм импорта — тоже.

## Цели

1. **Обычное приложение**: Dock, alt-tab, ОДНО окно с сайдбаром
   (Синк / Библиотека / Пульт). Меню-бар экстра остаётся как быстрый
   статус/действия. Внешний вид — нативный, в духе Музыки/iTunes.
2. **Пульт как управление библиотекой**: альбомы гридом с обложками,
   now-playing бар с обложкой и транспортом — не «список треков».
3. **Библиотека телефона на Маке**: что лежит на iPhone и что в облаке
   (бейджи по агрегированному cloud-состоянию альбома).
4. **Прогресс синка на Маке**: телефон пушит статус импорта в реальном
   времени (как на своём экране).
5. **Синк без конфирма на телефоне**: кнопка на Маке запускает импорт на
   iPhone через канал пульта (Мак уже спарен и авторизован — доверие есть).

## Протокол (ZverTransport, аддитивно в v1)

Новые теги `RemotePayload` (старые декодеры увидят `.unknown` и молча
проигнорируют — forward-compat уже заложен):

- Mac → iPhone: `startImport` (запустить импорт с ЭТОГО Мака);
  `requestArtwork(albumId)` (обложка альбома для грида/now-playing).
- iPhone → Mac: `artwork(albumId, data)` (JPEG ≤600px, `Data` → base64 в
  JSON-кодеке); `importStatus(RemoteImportStatus)` — пуш прогресса импорта.
- `RemoteImportStatus`: `{phase: idle|downloading|done|failed(unknown-совместим),
  albumTitle?, completedAlbums, totalAlbums, fraction, message?}` — один
  агрегированный статус, не по-файловый спам.
- `RemoteAlbum.cloudState: String?` (аддитивное поле, decodeIfPresent):
  `local|backedUp|remote|mixed` — агрегат по трекам альбома.
- `RemoteTrack.isCurrent`? — нет, индекс уже есть в `RemotePlayerState`.

## iOS

- `RemoteLibraryBuilder`: считает `cloudState` альбома; хелпер JPEG-обложки
  (через `ArtworkLoader`, даунскейл до 600, сжатие ~0.8).
- `RemoteControlService`:
  - `requestArtwork` → async загрузка → `artwork(...)` адресно клиенту;
  - `startImport` → инжектированный «лаунчер» headless-импорта;
  - наблюдает статус импорта → пуш `importStatus` всем авторизованным.
- **Headless-импорт** (`RemoteImportLauncher` в ContentView-вайринге):
  переиспользует стек этапа 3 — Bonjour-поиск синк-сервиса, сохранённый
  синк-токен, манифест, `ImportCoordinator.start()`, rescan + автобэкап
  (та же пост-обработка, что у кнопки в MacImportView). Уже идущий импорт →
  повторный `startImport` игнорируется (пуш текущего статуса). Ошибки — в
  `importStatus(failed)`.

## Mac

- **ZverMacApp**: убрать `LSUIElement` (обычная activation policy) → Dock и
  alt-tab; одна `Window`-сцена с `NavigationSplitView`: сайдбар
  Синк / Библиотека / Пульт; `MenuBarExtra` остаётся (статус очереди,
  быстрые действия, «Открыть окно»). Окно «Пульт» как отдельная сцена
  удаляется.
- **Синк** (существующий импорт-флоу + новое): дроп-зона/превью/очередь как
  есть; при подключённом пульте — кнопка **«Импортировать на iPhone»**
  (шлёт `startImport`) и живой прогресс-бар из `importStatus` (стадия,
  «N из M альбомов», доля). Пульт не подключён → подсказка.
- **Библиотека**: грид альбомов iPhone с обложками (lazy `requestArtwork`,
  NSCache + дисковый кэш в `~/Library/Caches`), бейдж облака по
  `cloudState`, поиск по названию/артисту. Тап — треки альбома
  (`requestAlbumTracks`) + «Играть на iPhone» (`playAlbum`).
- **Пульт**: now-playing бар с обложкой текущего альбома, транспорт,
  слайдер позиции; очередь со списком треков; библиотека — та же вкладка
  «Библиотека» (пульт = играющее сейчас, библиотека = что запустить).
- Общий `RemoteClientCoordinator` расширяется: кэш обложек, статус импорта,
  отправка новых команд.

## Верификация

Кодек новых тегов + cloudState + RemoteImportStatus — тесты в ZverTransport.
Headless-лаунчер: чистая часть (агрегация статуса) — тестируемая; сетевая —
сборкой. Оба таргета собираются. Ревью — один агент (Opus).
